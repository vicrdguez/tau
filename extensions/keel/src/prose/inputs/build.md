# Build inputs

The coordinator receives the [initial plan request](build/plan.md), a [request for one ready item's brief](build/brief-request.md), a [correction request](build/correction.md) or the [hand-off request](build/handoff.md).

The worker receives its [initial brief](build/brief.md), [review findings](build/rework.md) or [integration evidence](build/integration.md). Each link names the template for one situation.
