# Principle delivery failures

- An agent without the principle tool sees its index. An offered agent loses the index on a later render.
- Project names appear ahead of Keel's or in filesystem order. The index leaks bodies or a pull returns metadata instead of the body.
- A non-worker sees stale index text or a stale body after the principle file changes in its checkout.
- A worker's index, pull or rework input reads edited, removed or added checkout files instead of the snapshot pinned by its worktree effect. An empty snapshot falls back to the checkout.
- A worker fenced to a glob's directory, its parent or a normalized descendant misses the path-bound body. A wildcard in a directory component hides an applicable descendant. A sibling fence receives the body.
- A prose fence is admitted as a path, or a valid fence is stored with redundant prefixes or slashes (Build tests).
- Input rendering removes Markdown links from the delivered principle body.
- Shape omits model-the-domain. Ordinary rework gets attack-the-premise even though no addressed thread survived. A surviving fix or diagnosis misses its triggered bodies.
- A verifier sees only role-bound project principles instead of every project description.
- A ruling silently cites an unknown or index-only principle, or a body delivered to another conversation. A worker cannot cite a body actually delivered or pulled.
- An obsolete delivery task gives citation credit despite never submitting its input. Replaying a pull counts it twice or returns different text.
- A malformed project file blocks reconciliation, hides the remaining catalog, or grants citation credit. Repair is invisible until restart.
- A project principle with CRLF metadata is unavailable or loses a binding or body.
- An unknown role is silently accepted. A file with both a known and an unknown role still delivers its body.
- The verifier and owner receive a ruling stripped of the principles it cites.
- An unbound, paused or retired agent pulls a body (existing kernel author test), or sees the principle index even though pulls are refused. An active designer loses the index after adoption.
